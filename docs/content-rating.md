# Content rating (IARC questionnaire) — preparation notes

Play Console → App content → Content rating. The questionnaire wording changes over time; answer from the actual app, using these facts.

| Topic | Pawtiva 1.0.0 |
| --- | --- |
| App category in questionnaire | Utility / productivity-style app with game-like elements (not a game with gameplay levels to fight or race). If the form asks "Is your app a game?", answering **Yes** is also defensible because of XP, levels and a virtual pet; choose one and keep it consistent with the Play category (suggested category: **Productivity** or **Lifestyle**). |
| Violence, blood, fear | None. Cute illustrated kitten and puppy only. |
| Sexual content, nudity | None. |
| Language / profanity | None. |
| Controlled substances (drugs, alcohol, tobacco) | None. Habit icons include a pill emoji (💊) for "take medicine/vitamins" reminders; no drug references. |
| Gambling, simulated gambling | None. No random rewards, loot boxes or chance mechanics. |
| Digital purchases | **No real-money purchases.** PawCoins are a virtual currency earned only by completing habits; they cannot be bought. |
| User interaction / user-generated content shared with others | None. No chat, no social features, no sharing between users. |
| Shares user location | No. |
| Unrestricted internet / web browsing | No. |
| Personal information shared | No. Everything stays on device. |
| Ads | No ads. |

Expected outcome: the lowest age ratings (for example IARC 3+, PEGI 3, ESRB Everyone). The final rating is issued by IARC.

**Target audience (App content → Target audience and content):** open decision for the developer. Recommended: 13+ (or 18+) to stay outside the Families Policy unless you intend to design for children. If you include children under 13, the Families Policy and its additional requirements apply.
