# Store graphics

| File | Size / format | Play requirement |
| --- | --- | --- |
| `icon-512.png` | 512 × 512, 32-bit PNG (RGBA), ~9 KB | App icon: 512 × 512, 32-bit PNG with alpha, ≤ 1024 KB |
| `feature-graphic-1024x500.png` | 1024 × 500, 24-bit PNG (RGB, no alpha), ~79 KB | Feature graphic: 1024 × 500, JPEG or 24-bit PNG without alpha |

Both images are original artwork: the paw mark from the launcher icon and the code-drawn kitten and puppy with in-app accessories (crown, scarf, glasses). The wordmark uses Inter (SIL Open Font License). They contain no device frames, store badges, third-party logos, ranking or price claims, and no fake UI.

They were rendered from HTML/SVG with Playwright at device scale factor 1, so the pixel sizes are exact.

Suggested alt text (≤ 140 characters):
- Icon: "Purple paw print on a soft lavender background"
- Feature graphic: "A kitten and a puppy next to the Pawtiva name and the line: Build habits, grow together"
